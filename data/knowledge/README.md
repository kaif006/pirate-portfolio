# Chatbot knowledge base

Every other .md file in this folder is split into chunks, embedded and loaded into Supabase by `npm run ingest`.

Writing tips:
- Use third person ("Kaif built...").
- One topic per `## ` heading, so each chunk stays focused.
- Only include facts you are happy for visitors to see. Do not add your phone number.
- After editing, run `npm run ingest` again.
